# وقاية — نسخة محسّنة

هذه نسخة تطويرية مبنية على المشروع الأصلي، مع الاحتفاظ بجميع ملفات HTML وJavaScript ووظائفها.

## التحسينات
- تحسينات بصرية موحّدة على الصفحات مع تأثيرات تفاعلية خفيفة.
- مؤشر تقدّم القراءة وزر العودة لأعلى الصفحة.
- تنبيه عند انقطاع الاتصال بالإنترنت.
- دعم أفضل للوحة المفاتيح وإظهار التركيز، وإعدادات تقليل الحركة.
- تحسين ملاءمة الحقول للأجهزة المحمولة والطباعة.
- حماية الروابط الخارجية التي تفتح في تبويب جديد باستخدام `noopener noreferrer`.
- تحميل الصور غير الأساسية بصورة مؤجلة.

## التشغيل
افتح `index.html` عبر خادم محلي ثابت (مثل `python -m http.server 8000`) ثم افتح `http://localhost:8000`.
يفضّل عدم تشغيله مباشرة عبر `file://` لأن ملفات JavaScript تستخدم ES Modules.

## ملاحظات
- لم يتم تعديل مفاتيح أو إعدادات الخدمات السحابية الأصلية.
- بعض المزايا التي تتطلب اتصالًا أو إعدادات خارجية لا تعمل دون ضبط الخدمة المعنية.
- تم الحفاظ على الصفحات الأصلية والروابط الداخلية، ويُنصح باختبار الخدمات السحابية في بيئة النشر الفعلية.
